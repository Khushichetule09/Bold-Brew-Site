# Bold Brew Site ☕  
A sleek, responsive coffee-themed website built with modern front-end tooling for fast performance and reusable components.

## ⚙️ Tech Stack  
React • Vite • Tailwind CSS • JavaScript • HTML  

## 💡 Highlights  
- Clean, minimalist design tailored for a café/brand aesthetic  
- Highly responsive UI with reusable component architecture  
- Rapid build pipeline using Vite for optimized dev & production builds  
- Tailwind CSS for utility-first styling and rapid interface iteration
